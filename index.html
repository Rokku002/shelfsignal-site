About

Our first pipeline said “success” while a source was silently missing.

ShelfSignal started as a class project: an automated pipeline that collected grocery-delivery news every week. One run reported success, but one of its news feeds had quietly returned nothing. A brief built on that run would have looked confident and been wrong.

So the product was rebuilt around one rule: if you can’t see where a number came from, it doesn’t go in the brief. Today every figure carries its source, its record ID and its arithmetic.
